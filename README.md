# SPK Tumpangsari AHP

Sistem Pendukung Keputusan Pemilihan Kombinasi Tanaman Tumpangsari menggunakan metode AHP (Analytic Hierarchy Process).

## Setup

1. Copy `.env.example` ke `.env` dan isi dengan kredensial Firebase Anda.
2. `npm install`
3. `npm run dev`

## Deploy ke GitHub Pages

1. `npm run build`
2. `npm run deploy`
3. Tambahkan `username.github.io` ke Firebase Authorized Domains.
